## Setting Up Your Environment&#x20;

Setting up a environment can be a hard thing to understand for rookie teams and new team members.That is why this guide will assist you with it.

* [ ] Installing Android Studio
* [ ] Setting up the FTC Robot Controller
* [ ] Setting up FTCLIB

### Step 1: Install Android Studio

To install Android Studio [Install Android Studio](https://developer.android.com/studio) click the link and press the download button.Once the executable is downloaded, click on it, agree on the terms of service and set it up.Once you set it up, this screen will greet you.

### Step 2: Set up the FTC Robot Controller

To set up the FTC Robot Controller, [Download RC](https://github.com/FIRST-Tech-Challenge/FtcRobotController) click the link and once downloaded, extract it from ZIP.

<figure><img src="../.gitbook/assets/Screenshot 2026-01-24 at 20.49.03.png" alt=""><figcaption></figcaption></figure>

Next,click the Open Folder button in Android Studio and select the folder that you extracted.Once that folder is opened in Android Studio in the right bottom corner it will show a loading bar.Once that loading bar is gone with no errors,you are essentially ready to program your robot&#x20;
