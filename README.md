# Welcome

FirstPedia is designed to be the only platform that FTC and FRC teams will ever need, centralising everything teams need to know in a single website created by Cartesian Robotics #25153, we aim to make learning FTC and FRC super easy built around the philosophy:

> “Why should teams navigate countless resources, when one platform can lead them to success?”



This platform will include videos,documentations for different areas of FTC; such as but not limited to PR, Software, Electronics, Portfolio Management and Mechanics.It will also feature content for FRC,such as podcasts with FRC Dean's List Winners and their Dean's List essays.
